# Product specification

The maintained product requirements are in [the Lyo PRD](issues/prd.md).
[Spec 8](Specs/8-learning-evidence-loop.md) defines learning acceptance and retained
evidence; the [spec index](Specs/README.md) distinguishes implemented, partial and
deferred work. See [current development status](docs/development-status.md) for
the shipped source behavior.

Task-specific `spec.md` files generated by `lyo init <folder>` are separate input
templates for that workspace. This repository root is the product documentation
entry point, not an unfinished task template.
