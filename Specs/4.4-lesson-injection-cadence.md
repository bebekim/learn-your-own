# Lesson injection cadence

State: draft — broader pipeline cadence deferred (reviewed 2026-09-10)

The original five-stage proposal covered spec pickup, compile time, run start,
round failure and post-run analysis. Session finding delivery does not implement
all of those pipeline hooks.

## Current scope

- [x] Pipeline run guidance and delivery evidence exist in
      [pipeline](../src/runner/run-pipeline.ts) and [tests](../tests/pipeline.test.ts).
- [x] Session-start guidance and later explicitly applicable findings exist in
      [session hook](../src/lyo/selection/session-hook.ts); see
      [Spec 7](7-session-telemetry-lesson-bridge.md).
- [x] Native recovery decisions and registered task interventions have their own
      delivery/measurement lifecycle.
- [x] Post-run [trace analysis](../src/lyo/judge/trace-consumer.ts) updates the file
      library; its observational-credit limit remains in Spec 4.2.
- [ ] Add and test the proposed spec-pickup, compile-time and round-failure
      insertion points as a coherent pipeline contract.
- [ ] Retain each decision, including no delivery, its context, candidate version,
      actual selection probability where defined, and measured delivery cost.
- [ ] Rank interventions using validated outcome/cost evidence for the applicable
      task population; automatic semantic applicability is not implemented.

## Revised acceptance

A hook must identify an actual decision where guidance can alter work. It must
record what was delivered, avoid duplicate emission and allow later outcomes to
link back to that decision. More frequent injection is not itself improvement.

The former expected-prevented-loss formula is withdrawn as an implemented or
calibrated gate: posterior counters and failure recurrence do not measure the
causal benefit or cost of an intervention. Current prompt count limits are
operational bounds, not learned optima. Explicit activity tags are user-declared
scope, not semantic inference.

Before expanding cadence, establish a useful intervention with the
[registered comparison](8-learning-evidence-loop.md) and account for its context
cost. The deferred stages must be justified by a missed useful decision, not by
the availability of more telemetry.
