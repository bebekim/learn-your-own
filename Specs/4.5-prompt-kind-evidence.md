# 4.5 — Prompt-kind evidence

State: done — evidence/recompute implementation; accuracy uncalibrated
(reviewed 2026-09-10)

## Implemented behavior

- [x] [Classifier](../src/classification/prompt-kind.ts) and
      [typed observation](../src/types/observation.ts) separate classification from
      raw boundary construction.
- [x] [Evidence reducer](../src/reducers/prompt-kind-evidence.ts) stores prompt,
      kind, log score, method, evidence reference and time.
- [x] Positional and heuristic evidence is recorded at insertion; assistant
      response context supplies later evidence linked through turn identity.
- [x] Recompute sums evidence scores by kind and updates the denormalized current
      kind. This is an implemented scoring rule, not a calibrated probability.
- [x] [Tests](../tests/prompt-kind-evidence.test.js) cover evidence and recompute.
- [x] The formerly missing read-side consumer and historical backfill now exist
      in [Spec 4.6](4.6-prompt-kind-measurement.md) and
      [Spec 4.7](4.7-prompt-kind-evidence-backfill.md).

The initial method constants are positional 99, heuristic 3 and contextual 4
(stored in log form). They are hand-authored priors. Correlated text evidence,
agreement between methods and an argmax change do not validate those values or
prove accuracy. The previous assurance that later calibration would absorb
overconfidence is withdrawn; that work has not been demonstrated.

## Remaining scope

- [ ] Calibrate against independent labels relevant to the classification task.
- [ ] Add correction/outcome evidence only with explicit semantics and tests.
- [ ] Demonstrate that using the classification improves a downstream decision.

No embeddings or additional classifier are required by this spec. The original
four refactoring prerequisites have landed; their duplicate before/after plan is
removed. Descriptive measurement and learning acceptance remain separate:
[Spec 5](5-scoring-layer.md), [Spec 8](8-learning-evidence-loop.md).
